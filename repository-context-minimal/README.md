# Repository Context Minimal Starter

これは、Repository Contextを最小構成で始めるためのテンプレートです。

## ファイル構成

```text
AGENTS.md
REPOSITORY_CONTEXT.md
NEXT.md
HISTORY.md
```

## 使い方

1. このフォルダ内の4ファイルを、自分のプロジェクトのルートへコピーします。
2. `REPOSITORY_CONTEXT.md` に、目的・正本・現在地・注意点を書きます。
3. `NEXT.md` に、次にやることを3件だけ書きます。
4. `HISTORY.md` に、今日始めたことを書きます。
5. AIに「まず `AGENTS.md` と `REPOSITORY_CONTEXT.md` を読んで」と伝えます。

## 注意

- secret、password、API token、credentialを入れないでください。
- 顧客情報、個人情報、メール本文、契約書、請求書などの原本を入れないでください。
- 原本が別の場所にある場合は、複製ではなく参照先を書いてください。
- 最初から完璧に整理しようとせず、再開できる最小情報だけを書いてください。
