# Repository Context

## 目的

このプロジェクトは、何のためにあるかを書く。

例：

- 会社サイトを作る
- 研究ノートを整理する
- 業務ツールを作る
- AIとの作業を継続できるようにする

## 現在地

いまどこまで進んでいるかを書く。

- 進行中：
- 完了済み：
- 保留中：
- 実験中：

## ディレクトリ構成

```text
├── HISTORY.md
```

## してはいけないこと

入れてはいけない情報、勝手にやってはいけない操作を書く。

- secret、password、API token、credentialを入れない
- 個人情報、顧客情報、私的メッセージを入れない
- 明示的な承認なしに公開、送信、削除、デプロイしない
- 不明な事実を推測で補完しない

## 次に読むもの

新しい人間やAIが次に読むべきものを書く。

1. `AGENTS.md`
2. `NEXT.md`
3. `HISTORY.md`
4. 必要な正本や仕様書
