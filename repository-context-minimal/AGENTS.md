# AGENTS.md

## 目的

このプロジェクトでは、人間とAIが安全に作業を再開できるように、Repository Contextを使います。

## 最初に読むもの

変更作業の前に、次を読んでください。

1. `REPOSITORY_CONTEXT.md`
2. `NEXT.md`
3. `HISTORY.md`

必要に応じて、README、仕様書、正本データの参照先も確認してください。

## 作業ルール

- 依頼された範囲を優先してください。
- 既存の正本、採用済み判断、公開境界を尊重してください。
- 不明点を推測で埋めず、未確認として扱ってください。
- secret、password、API token、credential、個人情報、私的メッセージを追加しないでください。
- 明示的な承認なしに、削除、移動、公開、送信、デプロイ、外部サービス更新を行わないでください。
- 作業状態が変わった場合は、`NEXT.md` または `HISTORY.md` の更新を提案してください。

## 完了条件

作業は、次を満たしたときに完了とします。

- 依頼された変更または調査が終わっている
- 実施した確認、または未確認の理由が分かる
- 採用した判断や変更点が説明されている
- 残作業がある場合は `NEXT.md` に戻せる形で書かれている

## 迷ったとき

迷った場合は、次の順で確認してください。

1. ユーザーの最新指示
2. `REPOSITORY_CONTEXT.md`
3. 正本ファイルや参照先
4. `NEXT.md`
5. `HISTORY.md`

それでも判断できない場合は、作業を止めて確認してください。
