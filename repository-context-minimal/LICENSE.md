# License — CC0 1.0 Universal

この `repository-context-minimal/` 以下のテンプレートは、**CC0 1.0 Universal** として公開します。

自由にコピー、変更、再配布、社内利用、商用利用できます。クレジット表示は必須ではありません。

- SPDX: `CC0-1.0`
- Official: https://creativecommons.org/publicdomain/zero/1.0/
- Legal code: https://creativecommons.org/publicdomain/zero/1.0/legalcode

Repository Contextを導入するときに、ライセンス確認や著作権表記を運用上の負担にしないことを意図しています。
